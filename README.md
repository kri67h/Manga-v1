# Manga OCR Web Application

## Installation and Setup Instructions

### Prerequisites
- Ensure you have Node.js installed (version X.X or higher).
- Ensure you have MongoDB installed and running.

### Clone the Repository
```bash
git clone https://github.com/kri67h/Manga-v1.git
cd Manga-v1
```

### Installation
1. Install the necessary dependencies:
   ```bash
   npm install
   ```

### Running the Application
1. Start the MongoDB server:
   ```bash
   mongod
   ```
2. Start the application:
   ```bash
   npm start
   ```
3. Access the application at `http://localhost:3000` in your web browser.

### Usage
- Upload your manga images to initiate OCR processing.
- View the extracted text in the web interface.
